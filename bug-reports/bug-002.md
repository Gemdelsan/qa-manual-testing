# BUG-002: El sistema permite iniciar sesión a un usuario existente con una contraseña incorrecta

> **Nota:** Informe de incidencia simulado elaborado como práctica de documentación técnica y análisis de impacto de seguridad[cite: 23, 28, 29].

* **ID:** BUG-002[cite: 29]
* **Módulo:** Inicio de Sesión / Login (Veterinaria DAW)[cite: 9]
* **Entorno:** Entorno de pruebas simulado (análisis funcional sin ejecución en navegador real)
* **Precondiciones:** Existe una cuenta previamente registrada y activa con el correo `maria@correo.com`[cite: 9].

### Pasos para reproducir:
1. Acceder a la pantalla de inicio de sesión (Login) de Veterinaria DAW[cite: 9].
2. Introducir el correo electrónico registrado: `maria@correo.com`[cite: 9].
3. Introducir una contraseña incorrecta (ej: `PasswordErroneo123`)[cite: 9].
4. Pulsar el botón «Iniciar sesión»[cite: 9].

* **Resultado esperado:** El sistema rechaza el acceso, no permite la entrada y muestra el mensaje de error: *«Credenciales incorrectas»*[cite: 9].
* **Resultado obtenido:** El sistema acepta las credenciales erróneas y redirige al panel privado de la cuenta de usuario[cite: 9].

* **Severidad:** Crítica (Critical / Blocker) — Brecha grave de seguridad en la autenticación que permite el acceso no autorizado a cuentas ajenas y compromete la privacidad de los datos[cite: 9, 23, 29].
* **Prioridad:** Máxima / Urgente (Highest) — Requiere corrección inmediata antes de cualquier despliegue a producción[cite: 9, 29].
